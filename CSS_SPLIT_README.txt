CSS is opgesplitst:

css/style.css      = algemene basis: body, achtergrond, algemene .bubble, basisposities
css/account.css    = accountbol, login/register UI
css/search.css     = search/sitemap-bol UI
css/download.css   = download/upload/categorie-bollen
css/upload.css     = voorlopig leeg, voor uploadspecifieke regels
css/product.css    = product/MAX-bol zoals FamilieConnect
css/responsive.css = toekomstige globale responsive correcties

Vanaf nu kunnen we meestal één CSS-bestand aanpassen en terugsturen.
